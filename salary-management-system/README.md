
# Salary Management System

## Technologies
- Spring Boot
- Spring MVC
- Spring Data JPA
- Thymeleaf
- Bootstrap
- MySQL

## Functions
- Create Employee
- Read Employee
- Update Employee
- Delete Employee
- Search Employee
- Validation

## Run Project in VS Code

### Step 1: Create Database
Run file:
database.sql

### Step 2: Configure MySQL
Edit:
src/main/resources/application.properties

### Step 3: Run Project
Open terminal:

mvn spring-boot:run

### Step 4: Open Browser
http://localhost:8080
